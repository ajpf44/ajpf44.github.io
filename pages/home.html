Olá, me chamo Alexandre. Sou um desenvolvedor de software com experiência em Node.js, React, Spring Boot e SQL. Recentemente, concluí a Residência TIC/SOFTWARE no Serratec/Senac, onde obtive uma visão mais completa do desenvolvimento fullstack. Atualmente, estou estudando Java e Rust.

Linguagens Favoritas no github

Comecei a programar em 2017, na faculdade de física utilizando o Maple, com o foco em desafios de computação algébrica. Após isso estudei diversas linguagens, C, C++ e outras. Meu foco maior foi em javascript, onde entrei no desenvolvimento Web. Durante meu período na Residência do Serratec estudei banco de dados relacionais, Java com Springboot e React.
