O influence connect é uma aplicação web que conecta empresa e influenciadores. Responsiva e acessível, otimizando a criação e o gerenciamento das campanhas publicitárias.

Foi desenvolvida em apenas 3 semanas, como projeto final do curso de Resdiência em Software do Serratec em parceira com o Senac em 2024.

Utiliza as seguinte tecnologias 
- Backend: Java e Springboot
- Databse: PostgreSQL 
- Frontend: React com Typescript e Material UI
- Data Science: Python
